01 / PROBLEM

Inventory needs to move with operations

Warehouse and kitchen operations needed a mobile-friendly workflow for updating inventory information while keeping the underlying data centralized.

The workflow used Google Sheets as the data layer and AppSheet as the mobile interface. The setup supports role-based access and real-time inventory updates for operational users.
